Understanding logarithm results

A logarithm answers the question: what exponent produces a specified positive number from a given positive base? For log base 10, the result is the exponent applied to 10.

Worked check

Because 10² = 100, log₁₀(100) = 2. For other bases, the same definition applies: bˣ = y means log_b(y) = x.

Domain check

In real-number calculations, the base must be positive and different from 1, and the argument must be positive. Invalid inputs should not be treated as ordinary numeric results.

Logarithm Calculator: Formula, Examples and Usage Guide

A logarithm answers a reverse-exponent question: what power must a base be raised to in order to produce a given positive number? The relationship is log_b(x) = y when b^y = x. For example, log₁₀(1000) = 3 because 10³ = 1000. Logarithms are used in algebra, exponential growth, sound levels and other logarithmic scales, but scientific applications may require a specific reference value or model.

Formula and conditions

For argument x and base b, the change-of-base formula is log_b(x) = ln(x) / ln(b). The argument must be positive, the base must be positive, and the base cannot equal 1. Common logarithms use base 10; natural logarithms use base e, approximately 2.71828. A base of 1 is invalid because 1 raised to any power remains 1.

How to use the calculator

  1. Enter a positive argument—the number inside the logarithm.
  2. Enter a positive base other than 1.
  3. Calculate to find the exponent needed to reach the argument.
  4. Verify by raising the base to the answer; rounding can create a small difference.

Worked examples

Example 1: log₂(32) = 5 because 2⁵ = 32. Example 2: log₁₀(0.01) = −2 because 10⁻² = 0.01. Example 3: log₃(81) = 4 because 3⁴ = 81. A negative answer is valid when the positive argument is between 0 and 1; it does not mean the input was negative.

Interpretation and common mistakes

Keep the base and argument in the correct positions. log_b(x) is not the same as log_x(b). Do not enter zero or negative real arguments. Logarithms turn products into sums and powers into multipliers under the usual logarithm rules, but only for valid inputs and a consistent base. A mathematical answer alone does not determine the meaning of a decibel or pH value; those applications have their own definitions and reference scales.

Frequently asked questions

Can a logarithm be negative?

Yes. A positive argument smaller than 1 produces a negative result for a base greater than 1.

Why can the base not be 1?

Because 1 raised to any power is still 1, so no unique exponent can represent other arguments.

How do I check the result?

Raise the base to the calculated exponent and check whether it returns the original argument, allowing for rounding.
