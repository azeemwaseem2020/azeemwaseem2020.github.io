Logarithm formula

logb(x) = ln(x) ÷ ln(b), with x > 0, b > 0 and b ≠ 1.

Worked example

For x = 81 and base 3, log₃(81) = 4 because 3⁴ = 81.

Understanding logarithm results

A logarithm answers the question: what exponent produces a specified positive number from a given positive base? For log base 10, the result is the exponent applied to 10.

Worked check

Because 10² = 100, log₁₀(100) = 2. For other bases, the same definition applies: bˣ = y means log_b(y) = x.

Domain check

In real-number calculations, the base must be positive and different from 1, and the argument must be positive. Invalid inputs should not be treated as ordinary numeric results.
