Absolute Value Calculator

Calculate the absolute value of a number.

Enter values and calculate.

How to use

Enter any positive, negative, or zero value and select Calculate. The result shows the value's distance from zero without its sign.

Formula and notes

The absolute value is written as |x|. If x is zero or positive, |x| = x; if x is negative, |x| = −x.

Example

For x = −7, the absolute value is 7. For x = 7, the absolute value is also 7.

Quick guide: how to use this calculator

Absolute value removes the sign while keeping the number's distance from zero.

Formula or method

|x| = x when x ≥ 0; otherwise |x| = −x.

Useful note

Check that negative inputs are intentional; the result is always zero or positive.
