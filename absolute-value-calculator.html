What absolute value means

The absolute value of a real number measures its distance from zero on the number line. Direction is ignored, so positive and negative numbers that are equally far from zero have the same absolute value.

The standard definition is |x| = x when x ≥ 0 and |x| = −x when x < 0. Therefore, |−7| = 7, |7| = 7 and |0| = 0.

Worked examples

Example 1: |−12| = 12 because −12 is 12 units from zero.

Example 2: |4.5| = 4.5 because 4.5 is already non-negative.

Example 3: |8 − 13| = |−5| = 5, so the distance between 8 and 13 is 5 units.

Absolute value in algebra

Absolute value is useful when the size of a difference matters more than its direction. For example, |actual − target| gives the magnitude of an error without saying whether the error was above or below the target.

Common mistakes

Solving simple absolute-value equations

When an equation has the form |x| = 5, there are two solutions: x = 5 and x = −5, because both numbers are five units from zero. For |x − 3| = 5, the expression inside the bars must be either 5 or −5. Solving those two cases gives x = 8 or x = −2. This is different from simply removing the bars and keeping only the positive case.

Absolute value and measurement error

Suppose a measured length is 9.7 cm and the target is 10 cm. The signed difference is 9.7 − 10 = −0.3 cm, which tells you the measurement is below the target. The absolute error is |9.7 − 10| = 0.3 cm, which communicates the size of the difference without its direction. To understand whether a result is high or low, keep the signed difference as well as its absolute value.

Interpreting calculator results

This tool evaluates the absolute value of one entered real number. It does not solve an equation with an unknown variable or evaluate a full expression such as |a − b| unless you first calculate the expression's value. For multi-step algebra, simplify the inside expression carefully, then apply the piecewise definition. Absolute value is never negative; if a later calculation produces a negative result, check whether you have confused absolute value with a signed difference.

  • Do not treat absolute value as an ordinary sign-changing operation for every number.
  • Remember that |0| is 0.
  • For expressions such as |x − 3|, simplify the expression inside the bars before deciding its sign.

FAQ

Can an absolute value be negative?

No. The absolute value of a real number is always zero or positive.

Is absolute value the same as distance?

For one real number, |x| is its distance from zero. More generally, |a − b| is the distance between a and b on the number line.

Where is absolute value used?

It appears in distance problems, error measurements, algebraic inequalities and calculations involving differences.

Formula and calculation method

For a real number x, absolute value is defined piecewise: |x| = x when x is zero or positive, and |x| = −x when x is negative. The result is the distance from zero, so it can never be negative.

Practical example: measurement difference

If a target is 100 and the measured value is 96.5, the signed difference is 96.5 − 100 = −3.5, while the absolute difference is |−3.5| = 3.5. Keep the signed difference too if you need to know whether the measurement is above or below target.

Absolute value in real calculations

Absolute value measures distance from zero on the number line, so the result is never negative. For any real number x, |x| equals x when x is non-negative and equals −x when x is negative. For example, |−12| = 12, while |12| = 12. The sign of the original number is lost, so retain the signed value if direction matters.

Difference versus absolute difference

If a measured value is 96.5 and the target is 100, the signed difference measured minus target is −3.5, showing the measurement is below target. The absolute difference is 3.5, showing only the size of the gap. In error analysis, the absolute difference can be useful for magnitude, while signed error indicates whether a result is high or low.

Absolute value equations

Evaluating |x| for a known number is different from solving an equation. If |x| = 5, there are two solutions, x = 5 and x = −5, because both are five units from zero. Always consider both directions when solving an absolute-value equation, and check proposed solutions in the original equation.
