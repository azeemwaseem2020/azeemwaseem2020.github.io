How to calculate absolute value

The absolute value of a number is its distance from zero on the number line, so it is never negative. For a positive number, the absolute value is unchanged; for a negative number, the sign is removed; and |0| = 0.

Examples

|−7| = 7, |4.5| = 4.5, and |0| = 0. For an expression such as |x − 3|, the result depends on whether x − 3 is positive or negative.

Absolute value FAQ

Can absolute value be negative?

No. Its output is always zero or positive.

Is absolute value the same as distance?

For a single real number, its absolute value represents its distance from zero. More generally, the absolute value of a difference such as |a − b| represents the distance between a and b.

Absolute value formula and examples

The absolute value of a real number x is its distance from zero: |x| = x when x ≥ 0 and |x| = −x when x < 0.

Examples: |−12| = 12, |5.25| = 5.25, and |0| = 0. For two numbers, |a − b| gives their distance on the number line.

Common uses

Absolute value appears in algebra, error or difference calculations, distance problems, inequalities, and number-line questions.

FAQ

What is |−8|?
