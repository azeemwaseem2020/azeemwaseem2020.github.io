Quick guide: how to use this calculator

Enter the principal, annual rate and number of days, then review the growth under the stated daily-compounding assumption.

Formula or method

A = P(1 + r/365)ⁿ for daily compounding when 365 compounding periods per year are assumed.

Useful note

Actual financial products can use different day-count conventions, compounding rules and fees, so compare the assumption with the product terms.

Before you use the result

The result depends on the inputs, units and assumptions shown on this page. Check those details before using the result for a real-world decision.
