Velocity Calculator — Distance ÷ Time

Calculate average speed (the magnitude of average velocity) from distance and elapsed time and see the formula, units and calculation steps.

Calculate average velocity from distance and time

Important: This calculator uses distance ÷ elapsed time for average velocity magnitude. If direction is part of the problem, use displacement and a defined direction instead of treating distance as a vector.

Velocity and speed formula

For this basic calculator, the magnitude of average velocity is calculated from the supplied distance and elapsed time as v = d ÷ t. Strictly speaking, distance ÷ time gives average speed; average velocity uses displacement ÷ time and includes direction. With metres and seconds, the calculated magnitude is metres per second (m/s).

How to calculate speed or velocity magnitude

  1. Enter the distance travelled.
  2. Enter the elapsed time.
  3. Keep the distance and time units consistent.
  4. Divide distance by time to get the average speed (or velocity magnitude for a straight, one-direction motion).
  5. Report the result with its unit.

Worked example

If an object travels 100 m in 10 s, v = 100 ÷ 10 = 10 m/s.

Velocity vs speed

Velocity is a vector quantity, so true velocity includes direction. Speed describes only how fast something moves. This simple tool calculates the average velocity magnitude from distance and elapsed time; it does not accept direction.

Speed, distance and time

This relationship is also commonly searched as a speed calculator, speed distance time calculator, distance time calculator, or average speed calculator. If distance is in kilometres and time is in hours, the result is km/h. Convert the inputs when you need a different unit such as m/s.

Useful rearrangements are d = v × t for distance and t = d ÷ v for time. This page currently uses metres and seconds as its calculator inputs.

Common mistakes

  • Dividing by zero or entering a negative time.
  • Mixing kilometres with seconds without converting units.
  • Calling a distance-over-time result instantaneous velocity when motion is changing.
  • Ignoring direction when a vector velocity is required.

When to use this calculator

Use it for introductory physics, motion problems, classroom exercises, travel-rate checks and simple average-rate calculations when distance and elapsed time are known. It is useful for questions such as how fast did something travel?, what is the average speed?, and distance divided by time.

Average speed versus average velocity

Average speed uses total distance divided by total time. Average velocity uses net displacement divided by total time and has a direction. If an object travels 100 m out and then returns to its starting point, its total distance is not zero, but its net displacement is zero; the two averages therefore answer different questions.

Important limitation

This tool is intended for simple average velocity magnitude calculations. It does not model acceleration, instantaneous velocity, changing direction or detailed motion over time.

Velocity Calculator Guide

Use this calculator for the basic distance-and-time relationship. Because the current inputs are distance and elapsed time, the result represents average speed or velocity magnitude rather than a full directional velocity.

Formula

For directional motion, average velocity is v = Δx/Δt, where Δx is displacement. When only distance is available, the calculator uses v = d/t and reports the average velocity magnitude.

Worked example

If an object travels 120 m in 10 s, the calculated magnitude is 12 m/s. A true average velocity also requires the net displacement and its direction.

Velocity versus speed

Speed describes how fast an object moves. Velocity includes direction. For example, a trip that returns to its starting point can have nonzero total distance but zero net displacement.

Unit check

Use compatible units such as metres and seconds. If your source uses kilometres and hours, convert carefully before comparing the result with an SI value in m/s.

When this calculator is not enough

Use an acceleration or kinematics model when velocity changes during the interval, or when you need instantaneous velocity, changing direction, or a complete motion history.

MOTION MODEL CHECK

Velocity is a vector: displacement and distance are not interchangeable

Average velocity is displacement divided by elapsed time. Average speed is total distance divided by elapsed time. They can have the same numerical magnitude in a one-direction trip, but they answer different physical questions.

Use displacement

For velocity, use the change in position from start to finish, including direction where the problem requires it.

Use distance for speed

If the question asks how much path was travelled, use total distance and the speed relationship instead.

Round at the end

Keep useful precision during intermediate calculations and round the final value with its unit.
