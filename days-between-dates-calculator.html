Days Between Dates Calculator

Calculate the number of days between two calendar dates.

How it works

The result is the absolute difference between the two calendar dates. It does not count the start date as an additional full day.

Quick guide: how to use this calculator

Enter the two dates and choose the counting convention shown on the page to calculate the elapsed days.

Formula or method

Elapsed days are calculated from the calendar difference between the two dates.

Useful note

Inclusive counting can differ by one day from the standard elapsed-time convention.

Before you use the result

The result depends on the inputs, units and assumptions shown on this page. Check those details before using the result for a real-world decision.
