How to use

Enter the base radius and the perpendicular height using the same length unit. If you know the base diameter, divide it by two to obtain the radius before calculating.

Cone volume formula

V = (1/3)πr²h, where r is the base radius and h is the perpendicular height.

Worked example

For r = 3 cm and h = 10 cm: V = (1/3)π(3²)(10) = 30π ≈ 94.25 cm³.

Before you use the result

The result depends on the inputs, units and assumptions shown on this page. Check those details before using the result for a real-world decision or purchase.

Slant height is not vertical height

Use the perpendicular distance from the centre of the base to the cone's tip. The slant height follows the outside surface and is longer than the perpendicular height for an ordinary cone. If only the slant height and radius are known, the perpendicular height can be found using h = √(l² − r²), provided the measurements describe a right circular cone and l is at least as large as r.

Estimate material needs carefully

Volume measures the space inside a cone, not the area of sheet material needed to build its sides. For a container or pile, real-world capacity can be lower because of wall thickness, an uneven base, packing gaps or a truncated tip. Keep all input dimensions in one unit and report volume in the corresponding cubic unit.

Cone volume FAQ

Does height mean the slanted side?

No. The formula uses perpendicular height from the base to the apex, not the slant height.

What units does the result use?

The result is in cubic units corresponding to the units used for radius and height.

Calculation context

Cone volume uses the base area and height; for a circular cone, V = πr²h/3. The radius and height must use compatible units so the resulting volume is consistent.

Why cone volume is one-third of a cylinder

A cone with the same circular base radius and perpendicular height as a cylinder has one-third of the cylinder's volume. The cone formula is V = πr²h/3, while the cylinder formula is V = πr²h. For radius 3 cm and height 10 cm, the cone volume is 30π ≈ 94.25 cm³; the matching cylinder would be 90π ≈ 282.74 cm³.

Use perpendicular height, not slant height

The height in the volume formula is the straight perpendicular distance from the centre of the base to the apex. Slant height runs along the cone's sloping side and is not substituted directly into the volume formula. If only slant height is known for a right circular cone, the perpendicular height must first be found from the radius and slant height using the Pythagorean theorem, provided those measurements describe the same cone.

Check units and shape

Use compatible units for radius and height so the answer is in the corresponding cubic unit. This formula describes a right circular cone; irregular cones or objects with a truncated top require a different model. Real containers may also have wall thickness and a practical fill limit that reduce usable capacity.
