What the modulo operation does

Modulo returns the remainder after integer division. In the common expression a mod b, the result is the remainder left after dividing a by b, with the exact sign convention depending on the programming language or mathematical definition used.

Worked example

17 mod 5 = 2 because 17 = 5 × 3 + 2. Similarly, 24 mod 6 = 0 because 24 divides evenly by 6.

A practical Pakistan example

Modulo can help with repeating schedules. If a weekly cycle is represented by seven positions, a day count can be reduced with modulo 7 to find its position within the repeating cycle.

Common mistakes

Modulo is not ordinary division and is not the same as a percentage. Also check how negative operands are handled if you are comparing results between programming languages.

FAQ

What is 10 mod 3? 1.

What is 20 mod 5? 0.

Can the divisor be zero? No. Modulo by zero is undefined.

Modulo in practice

Modulo returns a remainder after division. For 17 mod 5, the remainder is 2. It is useful for repeating schedules, divisibility checks and programming. A 24-hour clock can wrap using modulo 24: 22 + 5 = 27 and 27 mod 24 = 3. Negative-number conventions can differ between programming languages, so use the calculator's stated convention.
