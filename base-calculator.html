Base Calculator

Convert an integer between common number bases such as binary, octal, decimal, and hexadecimal.

What is a number base?

A number system's base determines how many symbols are used for each digit position. Decimal is base 10, binary is base 2, octal is base 8, and hexadecimal is base 16. Bases above 10 commonly use letters for additional digit values.

Base conversion formula

For a positional number with digits d and base b, its value is the sum of each digit multiplied by the corresponding power of b. For example, binary 1011 equals 1×2³ + 0×2² + 1×2¹ + 1×2⁰ = 11 in decimal.

Common base examples

Decimal 10 is binary 1010, octal 12, and hexadecimal A. Decimal 255 is binary 11111111 and hexadecimal FF.

Where base conversion is used

Binary is fundamental to digital computing, hexadecimal is common in programming and memory representation, and octal still appears in some computing and permissions contexts. Base conversion is also useful in mathematics and computer science education.

FAQ

Why does hexadecimal use A–F? Base 16 needs sixteen symbols, so A through F represent decimal values 10 through 15.
