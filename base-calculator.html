Base Calculator

Convert an integer between common number bases such as binary, octal, decimal and hexadecimal.

How number bases work

A positional number system assigns each digit a place value based on powers of its base. Decimal is base 10, binary is base 2, octal is base 8 and hexadecimal is base 16.

Worked example

Binary 1011 equals 1×2³ + 0×2² + 1×2¹ + 1×2⁰ = 11 in decimal. Decimal 255 is FF in hexadecimal and 11111111 in binary.

Where base conversion is used

Binary is fundamental to digital systems, hexadecimal is common in programming and memory representation, and other bases are useful in mathematics and computer science.

FAQ

Why does hexadecimal use A–F? These symbols represent decimal values 10–15.

Which bases are supported? Integer conversion supports target bases from 2 through 36.

How base conversion works

A number written in one base is a positional representation. The same value can look completely different when the base changes because each digit is multiplied by a power of the base. For a number with digits dn...d1d0 in base b, its decimal value is:

Value = dnbn + ... + d1b + d0.

Worked example

Take 1011012. Starting from the right, the place values are 1, 2, 4, 8, 16 and 32. Therefore 101101 means 32 + 8 + 4 + 1 = 45 in decimal. Converting 45 back to binary gives 101101 because 45 = 32 + 8 + 4 + 1.

A practical Pakistan example

Base conversion is useful when checking computer or electronics values, reading hexadecimal identifiers, or translating a value shown by a programming tool into ordinary decimal notation. For example, a student working with a microcontroller project in Pakistan may receive a sensor register value in hexadecimal and convert it to decimal before comparing it with a measured value.

Common mistakes

Every digit must be smaller than the chosen base. A digit 8 or 9 is not valid in binary, and a digit A–F is only valid where the base supports those symbols, such as hexadecimal. Fractions also require a different positional treatment, so do not apply the whole-number rule to a fractional part without checking the method.

Base conversion FAQ

Can I convert between any two bases? Yes, provided the digits are valid for the source base. A reliable general method is source base → decimal → target base.

Why is hexadecimal convenient? One hexadecimal digit represents four binary bits, so long binary strings become much easier to read.

Does changing the base change the number? No. Correct conversion changes the representation, not the underlying numerical value.
