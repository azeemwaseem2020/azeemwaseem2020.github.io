Ideal Weight Calculator

Estimate ideal body weight using several established height-based formulas. Compare results rather than treating one estimate as a medical target.

How to use the ideal weight calculator

  1. Select sex as required by the chosen reference formula.
  2. Enter height in centimetres.
  3. Calculate the Devine reference estimate.
  4. Compare the estimate with other health measures rather than treating it as a target.

Worked example

For a 175 cm adult, the Devine formula gives approximately 70.1 kg for males and 65.6 kg for females.

Method

This tool uses the Devine formula as a reference estimate. Different formulas can produce different results, and body composition is not captured by height alone.

Calculation context

Ideal-weight estimates are formula-based reference ranges rather than individualized medical targets. Results depend on the selected formula and height, so the method and assumptions should be shown with the estimate.
