How to add fractions

To add fractions, first find a common denominator. Convert each fraction to an equivalent fraction with that denominator, add the numerators, and simplify the result.

Worked example

For 1/4 + 1/6, the least common denominator is 12. Convert the fractions to 3/12 and 2/12, then add them to get 5/12.

Unlike denominators

When denominators are different, adding the numerators directly is incorrect. The denominator represents the size of each part and must be made compatible before addition.

Fraction addition FAQ

Can I add mixed numbers?

Yes. Convert mixed numbers to improper fractions or add whole and fractional parts carefully, then simplify.

What if one denominator divides the other?

You can use the larger denominator as the common denominator when it is a multiple of the smaller one.

Fraction addition formula

For two fractions, a/b + c/d = (ad + bc) / bd. After adding, reduce the numerator and denominator by their greatest common factor.

Worked example

For 1/4 + 1/6, a common denominator is 12: 1/4 = 3/12 and 1/6 = 2/12, so the result is 5/12.

Common mistakes

  • Do not add denominators directly.
  • Do not forget to simplify the final fraction.
  • Check that denominators are not zero.

FAQ

Can fractions have different denominators?

Yes. Convert them to equivalent fractions with a common denominator first.

What if the denominators are already equal?

Add the numerators and keep the common denominator, then simplify.

How to add fractions correctly

When denominators match, add the numerators and keep the common denominator. When they differ, first find a common denominator and convert each fraction to an equivalent form.

Worked example

For 2/3 + 1/6, use 6 as the common denominator. Convert 2/3 to 4/6, then add 1/6 to get 5/6.

Check mixed numbers

If mixed numbers are used, convert them carefully or handle the whole-number and fractional parts consistently. A final simplification step helps catch arithmetic mistakes.

Adding-fractions FAQ

Why can't the denominators simply be added?

The denominator identifies the size of each fractional part. Adding denominators changes the unit instead of combining equal units, so it does not preserve the original values.
