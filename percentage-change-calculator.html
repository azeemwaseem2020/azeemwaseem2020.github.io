Percentage Change Calculator Guide

Percentage change compares a new value with an original value. A positive result indicates an increase and a negative result indicates a decrease.

Worked example

If a value changes from 80 to 100, the percentage change is ((100 − 80) ÷ 80) × 100 = 25%.

Why the starting value matters

The original value is the reference point. Changing the reference value changes the percentage result, so always confirm which value represents the starting point.

PERCENTAGE CALCULATION PATH

Percentage change uses the original value as the baseline

The standard percentage-change calculation divides the difference by the original value. That makes the direction of the change and the chosen baseline important when comparing two values.

Percentage change calculation context

Percentage change measures the relative difference between an original value and a new value. It is distinct from simply finding a percentage of a number and is useful for increases, decreases and before-versus-after comparisons.
