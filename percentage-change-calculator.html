Percentage Change Calculator Guide

Percentage change compares a new value with an original value. A positive result indicates an increase and a negative result indicates a decrease.

Worked example

If a value changes from 80 to 100, the percentage change is ((100 − 80) ÷ 80) × 100 = 25%.

Why the starting value matters

The original value is the reference point. Changing the reference value changes the percentage result, so always confirm which value represents the starting point.

Percentage Change: Formula, Direction and Worked Examples

Percentage change measures how far a value moves relative to its starting value. It is useful for comparing prices, monthly expenses, sales, grades, population figures and other measurements when the original value is a meaningful baseline. The sign matters: a positive answer means an increase and a negative answer means a decrease.

Formula

Percentage change = ((new value − original value) ÷ original value) × 100. The subtraction gives the absolute difference; dividing by the original value scales that difference to the starting point. Multiply by 100 to express the ratio as a percent. The formula requires a non-zero original value.

Worked examples

If a monthly bill rises from PKR 4,000 to PKR 4,600, change = (600 ÷ 4,000) × 100 = 15% increase. If a product price falls from PKR 2,500 to PKR 2,000, change = (−500 ÷ 2,500) × 100 = −20%, or a 20% decrease. If a score moves from 40 to 50, the increase is 25%, not 10%; 10 is the absolute point difference.

How to use this calculator

  1. Enter the starting or original value in the first field.
  2. Enter the later or new value in the second field.
  3. Confirm both values measure the same thing and use the same unit.
  4. Calculate and read the sign as well as the magnitude of the result.
  5. For a report, state the period and baseline, such as “monthly cost rose 15% from April to May.”

Features and practical applications

The calculator standardizes the comparison and helps avoid reversing the baseline. It can support month-over-month budgets, year-over-year revenue, price changes, energy usage, test scores and inventory monitoring. It is especially useful when the absolute differences look similar but the starting values differ substantially. A rise of 100 on a baseline of 500 is 20%, while the same rise on 2,000 is 5%.

Interpretation and limitations

The original value is the denominator, so reversing original and new values changes the result. A rise from 50 to 100 is 100%, while a fall from 100 to 50 is −50%; percentage increases and decreases are not symmetric. If the original value is zero, percentage change is undefined because division by zero is not possible. When the baseline is negative, the result may be mathematically calculable but can be hard to interpret; explain the context instead of relying on the sign alone.

Percentage change is different from percentage-point change. A rate moving from 20% to 25% rises by 5 percentage points, but its relative percentage change is 25%. Choose the measure that answers the actual question and avoid comparing values collected with different definitions or time windows.

Frequently asked questions

What does a negative percentage change mean?

It means the new value is lower than the original value under the standard formula.

Can I calculate percentage change from zero?

Not with this formula; a zero original value makes the denominator zero and the percentage change undefined.

Why is a 50% fall not cancelled by a 50% rise?

The second change uses a different baseline. Falling from 100 to 50 and rising from 50 to 75 ends at 75, not 100.
