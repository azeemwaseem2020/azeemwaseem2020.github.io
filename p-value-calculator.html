P-Value Calculator: What a Two-Sided Normal Approximation Means

This calculator estimates a two-sided p-value from a z statistic using the standard normal distribution. It answers a specific probability question under a statistical model; it does not measure the probability that a hypothesis is true or the size of an effect. The test design and assumptions must be appropriate before interpreting the number.

Concept and formula

For a z statistic under a standard normal null distribution, a two-sided p-value is P(|Z| ≥ |z observed|). It adds the probability in both tails beyond the absolute observed z value. A one-sided test asks a different question and uses only one tail, so its p-value is not generally the same as the two-sided result.

Worked example

If z = 1.96, the two-sided standard-normal p-value is approximately 0.05. This means that, if the null model and assumptions were true, a result at least this far from zero in either direction would occur about 5% of the time. It does not mean there is a 95% probability that the research hypothesis is true, nor does it tell you whether the observed effect is practically meaningful.

How to use the calculator

  1. Enter the z statistic from a test whose reference distribution is standard normal.
  2. Confirm whether the research question requires a one-sided or two-sided test; this tool reports the two-sided result.
  3. Read the approximate p-value and compare it with a significance threshold chosen before analysis.
  4. Report the effect estimate, uncertainty interval, sample size and study design alongside the p-value.

Limitations and good practice

The calculation uses a normal-tail approximation, so its accuracy depends on the underlying statistic and method. It is not a substitute for a t-test, chi-square test, exact test or model-specific p-value when those are required. Avoid interpreting p > 0.05 as proof of no effect or p < 0.05 as proof of causation. Statistical significance and practical importance are different concepts.

Frequently asked questions

Is a p-value the probability the null hypothesis is true?

No. It is a tail probability calculated assuming the null model and test assumptions.

Why is a two-sided p-value often larger?

It accounts for extreme results in both directions rather than one pre-specified tail.

Can I use this for every statistical test?

No. Use it only when a z statistic and standard-normal reference distribution are appropriate.
