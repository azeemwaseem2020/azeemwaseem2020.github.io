Stair dimensions and the rise-run relationship

Stair planning uses the vertical rise, horizontal run, number of steps and available space. A basic calculation is total rise = number of risers × riser height. The total horizontal run depends on the number of treads and tread depth. Building-code requirements vary by jurisdiction.

Worked example

If a floor-to-floor height is 2.8 m and 16 equal risers are planned, the nominal riser height is 2.8 ÷ 16 = 0.175 m, or 175 mm. The final design must still satisfy applicable code and practical comfort requirements.

Practical example

For residential construction in Pakistan, verify local building requirements and structural conditions before construction. This calculator is for dimensional planning, not a substitute for an architect, engineer or approved building plan.

Stair Calculations: Rise, Run and Proportion

Stair geometry is based on riser height, tread depth and the total vertical and horizontal dimensions. If total rise is known, the number of risers is approximately total rise divided by a chosen riser height, then adjusted so the risers are equal. The horizontal run is related to the number of treads and tread depth.

For example, a staircase with a total rise of 2.8 m and a target riser of 175 mm gives 16 risers exactly because 2,800 ÷ 175 = 16. The actual riser height is therefore 175 mm. Depending on the layout, the number of treads may be one fewer than the number of risers because the upper floor can act as the final landing.

A common comfort check is the relationship 2R + T, where R is riser height and T is tread depth. Designers use established building standards and local code requirements rather than relying on one universal number. In Pakistan, verify the applicable building regulations and project requirements before construction.

Measurement notes

Measure finished floor to finished floor for total rise when designing a complete stair. Account for floor finishes because tile, screed and other layers can change the final riser heights. A mathematically balanced staircase can still be unsuitable if the landing, headroom or structural support is inadequate.
