Stairs calculator: full guide

This tool estimates the number of stair risers from the total vertical rise and a preferred riser height. A riser is the vertical height between stair levels. Riser count and tread count may differ depending on the staircase layout, so the output is a starting estimate rather than a complete design.

Formula

Riser count = ceiling(total rise ÷ preferred riser height). Round up to a whole number so the full height can be covered. Then calculate actual equal riser height as total rise divided by the selected count.

How to use

  1. Measure the vertical distance between finished floor levels.
  2. Enter total rise and preferred riser height in the same units.
  3. Select Calculate to estimate the count.
  4. Recalculate actual riser height by dividing total rise by that count.

Example

For a total rise of 280 cm and preferred riser height of 17.5 cm, 280 ÷ 17.5 = 16, so the estimate is 16 risers. If the division is not a whole number, the calculator rounds up; check the resulting equal riser height before planning the layout.

Important design notes

Finished floor thickness, available horizontal space, tread depth, headroom, handrails and landings affect the final staircase. Unequal risers can cause trips. Building rules vary by location, so do not build from this count alone; have the complete design checked by a qualified professional. This tool estimates riser count only and does not confirm structural suitability or code compliance.

Frequently asked questions

What is a riser?

A riser is the vertical height from one stair tread to the next. The total floor-to-floor rise divided by the number of risers gives the planned height of each riser. Small rounding differences should be resolved in the design rather than leaving one step noticeably different.

Does this calculator confirm that a staircase meets code?

No. Stair regulations vary by location and building type and may set limits for riser height, tread depth, headroom, landings, handrails and consistency. Check applicable local requirements and have the layout reviewed by a qualified builder or designer before construction.

Why should I measure the total rise carefully?

Measure from the finished lower floor to the finished upper floor, including planned floor finishes. Omitting tile, carpet or flooring thickness can change the first or last riser and create a trip hazard.
