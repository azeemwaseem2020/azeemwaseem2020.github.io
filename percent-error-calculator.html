Percent Error Calculator

Calculate percent error from an experimental value and an accepted or reference value.

Percent error = absolute difference between experimental and accepted values divided by the absolute accepted value, multiplied by 100.

Complete guide to percent error

Percent error describes how far an experimental or measured result is from an accepted reference value, expressed as a percentage of the reference magnitude. It is commonly used in school laboratory reports, physics and chemistry experiments, calibration checks, and comparisons between a measured result and a published standard. A smaller percentage generally means the measurement is closer to the reference, but it does not by itself prove that a method is accurate or that the reference is correct.

Formula

Percent error = (|experimental value − accepted value| ÷ |accepted value|) × 100%

The absolute difference makes the error magnitude non-negative. Dividing by the absolute accepted value scales the difference relative to the reference, and multiplying by 100 converts the ratio into a percentage. The accepted value must not be zero because division by zero is undefined. If the reference can be negative in your field, this absolute-value form still reports the size of the discrepancy relative to its magnitude.

How to use this calculator

  1. Enter the result you measured in Experimental value.
  2. Enter the trusted or accepted comparison value in Accepted value.
  3. Select Calculate Percent Error.
  4. Read the percentage and check that both inputs use the same unit and refer to the same quantity.

Worked example

Suppose a lab measurement is 9.8 and the accepted value is 10. The absolute difference is |9.8 − 10| = 0.2. Divide by 10 to get 0.02, then multiply by 100: the percent error is 2%. If the experimental value is 10.4 against the same reference, the result is 4%. The direction of the difference is not shown by percent error; record whether the measurement was high or low separately if that matters.

Percent error vs. percent difference

Percent error compares one result with an accepted reference. Percent difference is often used to compare two values when neither is designated as the correct value, usually by dividing their absolute difference by a stated average. Do not substitute one formula for the other in a lab report. Percent error is also different from relative error, which is commonly the error ratio before multiplying by 100.

Interpretation and common mistakes

  • Use consistent units first—for example, convert centimetres to metres before comparing values.
  • Do not compare measurements of different quantities or conditions.
  • A zero reference cannot be used in this formula; report the absolute difference or choose a meaningful reference method instead.
  • More decimal places do not automatically mean a measurement is more accurate. Consider instrument resolution, repeatability, uncertainty and significant figures.
  • A low percent error does not establish statistical significance or explain the source of error.

This calculator provides a mathematical comparison, not a laboratory quality certification. Follow your course, lab, engineering or industry reporting rules for uncertainty and rounding.
