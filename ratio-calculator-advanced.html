How to compare two ratios

Enter the four values as A:B and C:D. The calculator converts each pair to a comparable value so you can see whether the relationships match. For a proportion, A/B = C/D, which is also equivalent to the cross-product check A×D = B×C.

When to use the basic ratio calculator

If you only need to simplify one ratio such as 12:18, use the Ratio Calculator. This advanced page is for comparing two ratios and checking proportional relationships.
