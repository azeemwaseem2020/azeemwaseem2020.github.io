Interest Rate Calculator

Find an implied effective interest rate per period from a present value, future value, and number of periods using a compound-growth model.

Interest rate formula

For a single effective growth rate per period, r = (FV ÷ PV)1/n − 1. Multiply r by 100 to express the result as a percentage per period. The formula assumes positive present and future values and a consistent period length.

Worked example

If PV = $10,000, FV = $12,000, and n = 2 periods, r = (12,000 ÷ 10,000)1/2 − 1 ≈ 9.5445% per period.

What this calculator measures

This calculator finds an implied compound-growth rate from two values. It is not automatically an APR, APY, loan rate, or inflation rate unless the period definition and compounding convention match those concepts.

How to use it

Enter the starting value, ending value, and number of equal periods. Keep the time unit consistent—for example, monthly periods should be interpreted as monthly periods throughout the calculation.

FAQ

Is the result an annual interest rate? Not necessarily. It is a rate per input period. Annualizing it requires knowing the period and compounding convention.

What happens if future value is lower than present value? The implied rate can be negative, representing a decline rather than growth.

Can this calculate loan APR? Not directly. Loan APR calculations can include payment timing, fees, and other terms.
