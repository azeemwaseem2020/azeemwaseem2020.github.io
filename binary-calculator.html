Quick guide: how to use this calculator

Enter the binary value and choose the conversion you need. Binary uses only 0 and 1.

Formula or method

Each binary digit represents a power of 2; the rightmost digit is 2⁰.

Useful note

Do not enter digits other than 0 and 1 in a binary value.
