Binary Calculator

Convert binary numbers to decimal, check binary input, and understand how base-2 place values work.

What is a binary number?

A binary number uses only two digits: 0 and 1. This is called the base-2 number system. Computers and digital electronics use binary because electronic circuits can represent two distinct states, such as off and on. A sequence such as 101101 is therefore a number, not a decimal code that needs to be interpreted as ordinary decimal digits.

How binary to decimal conversion works

Each position in a binary number has a value based on a power of 2. The rightmost position is 2⁰ = 1, the next is 2¹ = 2, then 2² = 4, 2³ = 8, and so forth. Multiply each binary digit by its position value and add the results. Positions containing 0 contribute nothing; positions containing 1 contribute their corresponding power of 2.

Worked example: 101101₂

For 101101₂, the 1s occur at 2⁵, 2³, 2² and 2⁰. Therefore: 32 + 8 + 4 + 1 = 45₁₀. The calculator above performs the same conversion instantly and also rejects characters other than 0 and 1.

Decimal to binary

To convert a positive decimal integer to binary manually, divide the number by 2 and record the remainder. Continue dividing the quotient by 2 until it reaches zero. Read the remainders from bottom to top. For example, 45 divided repeatedly by 2 produces remainders that read as 101101, so 45₁₀ = 101101₂.

Binary and other number systems

Binary is useful for understanding how computers represent data, while hexadecimal and octal provide shorter ways to write groups of binary digits. Four binary bits correspond to one hexadecimal digit. For example, 1010₂ is A₁₆. Learning these relationships makes binary, hexadecimal, and bit-level calculations easier to follow in programming and computer science.

Common uses of binary

Binary representation appears in digital logic, computer architecture, programming, networking, bit masks, permissions, and data encoding. A bit can hold either 0 or 1, while eight bits form one byte. Larger values can be represented by combining more bits, although the exact interpretation depends on whether the data is unsigned, signed, encoded text, an instruction, or another data type.

Binary calculator tips

  • Use only 0 and 1 in the input.
  • Leading zeros do not change the decimal value.
  • For large binary integers, use a calculator that preserves integer precision.
  • Remember that converting a number is different from interpreting a binary data field with a specific encoding.

FAQ

What digits are valid in binary?

Only 0 and 1 are valid digits in an ordinary base-2 number.

How do I convert binary to decimal?

Assign powers of 2 from right to left, multiply each digit by its position value, and add the results.

How do I convert decimal to binary?

For a positive integer, repeatedly divide by 2 and read the remainders in reverse order.

Why do computers use binary?

Digital hardware can reliably represent two states, making a two-symbol number system practical for electronic computation.
