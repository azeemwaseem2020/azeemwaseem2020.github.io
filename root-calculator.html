Nth root calculator: complete guide

The nth root of a number is a value that, when raised to the power n, produces the original number. Square roots use n = 2, cube roots use n = 3, and higher roots extend the same idea. Roots are the inverse operation of raising a number to a power and appear in algebra, geometry, science and scaling calculations.

Formula

Root = x1/n, where x is the input number and n is the root index. For example, the cube root of 27 is 3 because 3³ = 27. The fourth root of 16 is 2 because 2⁴ = 16.

How to use it

  1. Enter the number whose root you want in N.
  2. Enter the root index in R as a positive whole number.
  3. Select Calculate and check the displayed result.
  4. Verify by raising the result to the chosen index, allowing for rounding.

Negative numbers and limitations

Odd roots of negative numbers are real; for example, the cube root of −8 is −2. Even roots of negative numbers are not real numbers, so this calculator reports an invalid result for that case. A root index of zero is undefined, and fractional or non-integer indices are not accepted by this tool. Decimal output may be rounded, so it may not reproduce the original value exactly when raised to a power.

Use consistent interpretation of signs and powers, and distinguish the root index from the number being rooted. This calculator provides a numerical root; it does not factor polynomials or solve general equations.

Frequently asked questions

What is the difference between a square root and an nth root?

A square root is the number that gives the original value when multiplied by itself. An nth root generalises the idea: raising the result to the power n returns the radicand. For example, the cube root of 27 is 3 because 3³ = 27.

Can I calculate the root of a negative number?

Odd roots of negative real numbers are real, such as the cube root of −8 being −2. Even roots of negative numbers are not real numbers; they require complex-number mathematics, which a basic real-valued calculator may not support.

Why does the root change when I change the index?

The index states which power reverses the root operation. A square root uses index 2, a cube root uses index 3, and a fourth root uses index 4. Always check the index and whether your result is real before using it in a later calculation.

Understanding the index and radicand

In an expression such as the nth root of x, n is the index and x is the radicand. A square root has index 2, a cube root has index 3, and a fourth root has index 4. The result is a number which, raised to the index power, gives the radicand, subject to the real-number domain.

Examples and domain rules

  • √25 = 5 because 5² = 25.
  • ∛(−27) = −3 because (−3)³ = −27.
  • The real fourth root of 16 is 2; an even root of a negative real number is not real.
  • The index must be a positive integer for the usual real nth-root interpretation.

Floating-point calculations may show a small rounding difference for roots that are not exact. If you are solving an equation, remember that an even-power equation can have both positive and negative solutions even though the principal square root is non-negative. This tool provides a numerical root estimate and does not replace checking the original equation.
