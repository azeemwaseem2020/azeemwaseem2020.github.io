Permutations versus combinations

The key question is whether order matters. A permutation counts arrangements where changing the order creates a different outcome. A combination counts selections where the same members in a different order are still one group. This distinction is easy to miss when solving scheduling, committee or probability questions.

Formula

Permutations: P(n,r) = n! ÷ (n−r)!. Combinations: C(n,r) = n! ÷ [r!(n−r)!]. Here n is the total number of available items and r is the number selected or arranged.

Worked example

If 5 students are available and 3 positions must be filled, order matters for the positions: P(5,3) = 5 × 4 × 3 = 60. If instead a 3-person committee is selected, order does not matter: C(5,3) = 10.

Pakistan-specific example

A university society in Pakistan might select three volunteers from five applicants for a committee. That is a combination if all committee members have equal status. If the three positions are president, secretary and treasurer, it becomes a permutation because the roles are different.

Common questions

When do I use combinations? When order does not create a new outcome.

Can r be larger than n? No for the standard formulas used here.

Why does factorial grow quickly? Each additional positive integer multiplies the previous product.

Is this a probability calculator? It provides counting values that can be used inside probability calculations.
