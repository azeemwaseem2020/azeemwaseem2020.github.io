Voltage Divider Calculator

Estimate the output voltage from a two-resistor divider. Enter the source voltage and resistor values to calculate the ideal, unloaded output.

Voltage divider formula

For two resistors in series, with R1 between the input and output node and R2 between the output node and ground, the ideal output is:

Vout = Vin × R2 ÷ (R1 + R2)

Use the same resistance unit for both resistors (for example, Ω with Ω or kΩ with kΩ). The ratio is unchanged by converting both values consistently. The formula assumes a stable input source and no significant load connected to the output.

Worked example: 12 V input

Suppose Vin = 12 V, R1 = 1 kΩ and R2 = 1 kΩ. The resistors are equal, so the output is half the input:

Vout = 12 × 1,000 ÷ (1,000 + 1,000) = 6 V.

If R1 = 2 kΩ and R2 = 4 kΩ with the same 12 V input, Vout = 12 × 4 ÷ 6 = 8 V. A larger lower resistor produces a larger share of the input voltage across R2.

How to use this calculator

  1. Enter the source voltage in volts. Negative values are accepted for circuits with a reversed reference polarity.
  2. Enter R1, the resistor from the source side to the output node.
  3. Enter R2, the resistor from the output node to ground or the reference node.
  4. Select Calculate Output Voltage and read the result in volts.

R1 and R2 must be non-negative, and their sum must be greater than zero. This tool calculates the ideal divider equation; it does not estimate power dissipation, resistor tolerance or a connected load automatically.

Why output loading matters

A device connected to the output can draw current. Its input resistance effectively sits in parallel with R2, reducing the lower-leg resistance and usually lowering the output voltage. If the load resistance is Rload, use the parallel equivalent Rlower = (R2 × Rload) ÷ (R2 + Rload), then substitute Rlower for R2 in the divider formula.

As a practical rule, the load input resistance should be much larger than R2 if you want the unloaded calculation to remain a good approximation. For a sensitive circuit, calculate with the load included and check the resistor tolerances and source impedance.

Power and component limits

The divider current in the unloaded ideal circuit is I = Vin ÷ (R1 + R2). Resistor power can be estimated with P = I²R for each resistor. Check that the calculated power stays comfortably below the component's rated power, and consider voltage ratings, temperature, tolerance and wasted current. A simple divider is often suitable for sensing or setting a reference, but it is usually not a good regulated power supply for a changing load.

Common applications

  • Scaling a sensor or signal voltage to a range an input can measure.
  • Creating a bias voltage or a simple reference point in a high-impedance circuit.
  • Estimating the output of a series-resistor network during basic electronics learning.

Frequently asked questions

Which resistor is used in the numerator?

R2, the resistor between the output node and ground/reference. The output is measured across R2 in this standard arrangement.

Can either resistor be zero?

The ideal equation permits R1 = 0 when R2 is positive, giving Vout = Vin, and R2 = 0 when R1 is positive, giving Vout = 0. Both cannot be zero because the denominator would be zero. Real circuits still have source and wiring resistance.

Why does my measured voltage differ from the result?

Common causes include a connected load, resistor tolerance, source-voltage variation, wiring resistance, meter input impedance and incorrect resistor placement. Measure the actual component values and include any significant load in the model.

Can I use a voltage divider to power a device?

Only when the load is very small and predictable and the voltage variation is acceptable. For loads that change current or require stable voltage, use an appropriate regulator or power-supply circuit.
