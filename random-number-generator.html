How browser random numbers work

This tool generates an integer between the selected minimum and maximum values. The endpoints are included when the calculator is configured for an inclusive range. A range such as 1 to 6 therefore models a six-sided die, while 1 to 100 can provide a simple random integer for games, classroom exercises or quick selections.

Worked example

If the minimum is 10 and maximum is 20, every generated result is intended to fall within that interval. Running the generator again can produce a different value because each draw is a separate random selection.

Important limitation

A normal browser random-number generator is suitable for everyday randomization, testing and games, but should not automatically be treated as a cryptographic source. Passwords, security tokens, financial secrets and other security-sensitive values require a cryptographically secure random-number generator designed for that purpose.
