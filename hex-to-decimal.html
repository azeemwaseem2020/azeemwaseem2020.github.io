Converting hexadecimal to decimal

Hexadecimal is a base-16 number system that uses digits 0–9 and letters A–F. Each position represents a power of 16. Converting hexadecimal to decimal means multiplying each digit by its positional value and adding the results.

Formula

For hexadecimal digits dₙ…d₀, decimal value = Σ(dᵢ × 16ⁱ), starting from i = 0 at the rightmost digit. A=10, B=11, C=12, D=13, E=14 and F=15.

Worked example

Hex 2F = 2×16 + 15 = 47 in decimal. Hex 1A3 = 1×256 + 10×16 + 3 = 419.

Pakistan-specific example

A computer-science student in Pakistan may encounter hexadecimal in memory addresses, colour codes or low-level programming. For a web colour such as #FF8800, each pair is a hexadecimal channel value; conversion helps explain the underlying numeric representation.

Common questions

Why does hex use letters? Six extra symbols are needed for values 10–15.

Is FF equal to 255? Yes, because 15×16+15 = 255.

Can lowercase letters be used? Yes; A–F and a–f represent the same values.

Is hexadecimal a different value? It is a different representation of the same underlying integer.
