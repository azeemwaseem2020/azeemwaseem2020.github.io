Ratio Calculator Guide

A ratio compares quantities of the same kind. This calculator reduces two values by their greatest common factor so the relationship is easier to read.

Worked example

A ratio of 24:36 has a greatest common factor of 12, so 24:36 simplifies to 2:3.

Unit check

Convert comparable quantities to compatible units before simplifying. A ratio such as metres to centimetres should be converted first if the units are not intentionally different.

Where ratios are useful

Ratios are common in recipes, mixtures, scale drawings, maps, dimensions and comparisons between quantities.

How to use the ratio calculator

Enter the quantities in the ratio and choose the operation you need. The calculator can help simplify ratios and identify equivalent ratios for common comparison problems.

Check your units

Ratio values should describe comparable quantities. Convert units first when the two quantities are expressed using different measurement units.

Ratio Calculator

Simplify a ratio and compare two quantities using their greatest common factor.

Ratio formula

Simplified ratio = divide both values by their greatest common factor (GCF).

How to simplify a ratio

  1. Enter the two values in the same order as the ratio.
  2. Find the greatest common factor shared by both values.
  3. Divide both values by that GCF.
  4. Write the resulting values as the simplified ratio.

Worked example

For 12:18, the GCF is 6. Divide both values by 6: 12 ÷ 6 : 18 ÷ 6 = 2:3.

Equivalent ratios

Equivalent ratios keep the same relationship. For example, 2:3, 4:6 and 10:15 describe the same proportion because both parts are multiplied by the same factor.

Common uses

Ratios are useful for recipes, mixtures, maps, screen dimensions, finance comparisons, scale drawings and quantity planning.

What this calculator does

This tool simplifies two values into their lowest ratio using the GCF. It does not currently solve for a missing value in a proportion.

Ratio calculation context

A ratio compares quantities in the same relationship. For example, 2:3 means that for every 2 parts of the first quantity there are 3 parts of the second. Simplifying 20:30 to 2:3 changes the numbers but preserves the relationship.

Ratio vs fraction

A ratio such as 2:3 can be written as the fraction 2/3 when the question asks for the first quantity relative to the second. The notation is not automatically a percentage; convert to a percentage only when the context calls for it.

Ratios compare quantities in relative terms. A ratio can be simplified, scaled or converted into related percentage and proportion calculations depending on the problem.

Define the event before calculating probability

Probability describes uncertainty on a scale from 0 to 1, where 0 means impossible under the model and 1 means certain. The simple formula favourable outcomes ÷ total outcomes applies only when the listed outcomes are equally likely and the sample space is complete.

Worked example: a fair six-sided die

The probability of rolling an even number is 3/6 = 1/2 = 50%, because the favourable outcomes are 2, 4 and 6. The probability of not rolling an even number is the complement, 1 − 0.5 = 0.5. This complement rule applies to any event and its exact opposite.

Independence and changing sample spaces

For independent events A and B, P(A and B) = P(A) × P(B). In a draw without replacement, the second draw's probabilities change because the sample space changes. Do not multiply probabilities as if events were independent unless assumptions support it. Observed frequency is also not automatically theoretical probability.

Frequently asked questions

Can probability exceed 100%?

No. A valid probability is between 0% and 100%, inclusive.

Are odds the same as probability?

No. Probability compares favourable outcomes with all outcomes; odds compare favourable outcomes with unfavourable outcomes.

When can I use favourable outcomes divided by total outcomes?

When outcomes are equally likely and the sample space is correctly defined. Otherwise, a suitable probability model or data-based estimate is needed.
