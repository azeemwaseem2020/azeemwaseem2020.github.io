How to solve a quadratic equation

Enter the coefficients a, b and c for an equation in the form ax² + bx + c = 0. The discriminant helps describe the roots, while the calculator provides the resulting solutions.

Check the coefficients

Make sure a is not zero when you intend to solve a quadratic equation. Use the displayed result to verify the roots in the original equation.

Solve ax² + bx + c = 0

Quadratic formula

x = (−b ± √(b² − 4ac)) ÷ 2a

What the discriminant means

The discriminant is D = b² − 4ac. If D is positive, there are two distinct real roots. If D is zero, there is one repeated real root. If D is negative, the roots are complex.

How to use the quadratic equation calculator

  1. Enter the coefficients a, b and c.
  2. Make sure a is not zero so the equation remains quadratic.
  3. Select Solve Equation.
  4. Review the discriminant and roots shown in the result.

Worked example

For x² − 5x + 6 = 0, the coefficients are a = 1, b = −5 and c = 6. The discriminant is 1, so the roots are x = 2 and x = 3.

Common mistakes

Keep the signs of b and c when substituting into the formula. Also check the denominator 2a and verify the resulting roots in the original equation when accuracy matters.

Real and complex roots

A negative discriminant means there are no real roots. This calculator displays the corresponding complex roots in the form real ± imaginary i.

Important limitation

This calculator handles a quadratic equation in one variable in standard form ax² + bx + c = 0. It does not expand or rearrange a general equation entered as text.

Common questions

How should I check the answer?

Substitute the calculated value back into the original equation. The two sides should agree within normal rounding.

What if the inputs do not define one solution?

The solver reports special cases such as no solution or infinitely many solutions instead of forcing a misleading numeric answer.

Quadratic equation calculation context

Quadratic equations contain a squared variable and can have zero, one or two real roots depending on the discriminant. This makes the quadratic calculator a natural next step from linear equation solving.
