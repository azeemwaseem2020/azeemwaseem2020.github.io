- Meta description: Explore free online calculators for Pakistan finance, PSX profit, solar load, TMR feed, fertilizer and everyday maths, with clear formulas and practical examples.
- Keep canonical at the homepage URL. Keep title and Open Graph/Twitter titles aligned unless a specific reason supports a difference.
- Keep the homepage H1 focused on calculator discovery. Mention specialist topics in helpful navigation and short descriptions rather than repeating keyword variants unnaturally.

## Internal-link rules

1. Homepage → topic hubs and a small set of important tools.
2. Hub → relevant calculator pages with descriptive, natural anchor text.
3. Calculator → its parent hub and 2–4 closely related tools where useful.
4. Guides → the calculator that solves the guide's stated problem, and vice versa.
5. Do not create links to nonexistent URLs; verify every path in the repository before publishing.
6. Each page must have one clear primary intent. Similar terms can be supporting language, not a reason to create duplicate pages.

## Validation and measurement

- Confirm every URL exists and returns 200.
- Inspect title, meta description, canonical, H1, indexability and internal links.
- Check structured data with a validator; only include schema that matches visible content.
- Test calculator math and edge cases before changing or adding features.
- Compare Google Search Console query/page data over 28-day and 90-day periods; monitor impressions, clicks, CTR and average position.
- Revisit keyword assignments when Search Console shows two URLs competing for the same query.
- Never promise first-page rankings. Ranking depends on relevance, competition, site quality and Google's systems; this plan establishes a measurable foundation, not a guarantee.
