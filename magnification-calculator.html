Interpreting optical magnification

Magnification compares image size with object size. A magnitude greater than one means the image is larger than the object, while a value below one means the image is smaller. The sign of magnification can also carry information about image orientation in optics, but sign conventions depend on the lens or mirror model being used. This calculator uses the size ratio, so apply the sign convention from your course separately when orientation is required.

Formula

Magnification m = image height ÷ object height. Rearranging gives image height = m × object height and object height = image height ÷ m. Both lengths must use the same unit before division.

Worked example

If an object is 0.02 m high and its image is 0.04 m high, m = 0.04 ÷ 0.02 = 2. The image is twice the object's height in magnitude. If the object height were 20 mm and image height 40 mm, the same result would be obtained because the units are consistent.

Pakistan-specific example

A physics student preparing for an optics practical at a college in Punjab might measure an object height in centimetres and the image height in centimetres on a screen. Keeping both measurements in centimetres avoids an unnecessary conversion. For an actual optical bench experiment, measurement uncertainty, alignment and lens position can affect the observed ratio.

Common questions

What does m = 1 mean? The image and object have equal size in magnitude.

Does m = 0.5 mean the image is half-size? Yes, in magnitude.

Does this calculate focal length? No. Use the lens or mirror equation for focal length.

Why might a textbook show negative magnification? Its sign convention may encode an inverted image.

For an experiment, record whether the image is upright or inverted separately from its size ratio. A numerical magnitude alone cannot describe orientation. If measurements are taken from a screen or ruler, keep the same reference points and avoid mixing image height with image distance.
