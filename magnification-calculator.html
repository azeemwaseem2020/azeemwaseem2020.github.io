Magnification Calculator: Image Size and Object Size

Magnification compares the size of an image with the size of the original object. It is a ratio, so it has no unit as long as both sizes are measured in the same unit. A magnification magnitude greater than one indicates a larger image; a magnitude below one indicates a smaller image. In optics, the sign may also convey image orientation, depending on the convention used.

Formula

Magnification m = image size ÷ object size. Rearranging gives image size = m × object size, and object size = image size ÷ m. Enter any two positive values; the calculator never silently assumes m = 1. This calculator uses sizes to find a ratio; it does not model a lens or mirror system from focal length and object distance.

Worked example

If an object is 0.02 m tall and its image is 0.04 m tall, the size ratio is 0.04 ÷ 0.02 = 2. The image is twice the object's size. If the image is 0.01 m while the object remains 0.02 m, magnification magnitude is 0.5, meaning the image is half as tall. Both sizes must use the same unit for the ratio to be interpreted correctly.

How to use the calculator

  1. Measure or enter the image size and object size in matching units.
  2. Ensure object size is not zero, because division by zero is undefined.
  3. Calculate and interpret the result as a size ratio.
  4. If your assignment uses signed magnification, apply the sign convention specified in that course or textbook.

Real-world measurement tips

For microscope or camera images, clarify whether you are measuring a printed image, a screen representation or the actual image formed by the optical system. Scaling a photograph on a display changes its displayed dimensions without changing the original optical magnification. Measurement uncertainty also matters: rounding both small dimensions too aggressively can distort the ratio. This tool is most useful when the two measured sizes refer to the same object and image relationship.

Frequently asked questions

Does magnification have a unit?

No. It is a ratio of two lengths expressed in the same unit.

Does a value of 2 mean two times larger?

In magnitude, yes: the image size is twice the object size.

Can this calculate focal length?

No. Use a lens or mirror equation calculator when focal length and distances are the unknowns.
