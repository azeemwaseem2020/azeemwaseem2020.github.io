Using the spherical-mirror equation

The mirror equation connects focal length, object distance and image distance for an ideal spherical mirror. It is most useful when the problem follows the assumptions of paraxial optics, where rays close to the principal axis are considered. The numerical answer also depends on the sign convention used by the textbook or laboratory. Calcora shows the algebraic relationship, but you should keep the convention consistent throughout the problem.

Formula

1/f = 1/dₒ + 1/dᵢ. If focal length and object distance are known, image distance is dᵢ = 1 ÷ (1/f − 1/dₒ). Similar rearrangements allow focal length or object distance to be found.

Worked example

Using a simplified magnitude example with f = 0.20 m and dₒ = 0.40 m, 1/dᵢ = 1/0.20 − 1/0.40 = 5 − 2.5 = 2.5 m⁻¹, giving dᵢ = 0.40 m. The result should then be interpreted with the sign convention and mirror type used in the question.

Pakistan-specific example

A physics student in a Pakistani intermediate or undergraduate lab might measure an object and screen position around a concave mirror. Record distances in metres or centimetres consistently, then compare the calculated image distance with the observed position. Experimental differences can arise from alignment and measurement uncertainty.

Common questions

Why can image distance become negative? Under many sign conventions, the sign indicates image location or orientation rather than an error.

Can this model handle any mirror? It is intended for standard spherical-mirror problems, not arbitrary mirror geometries.

What happens near the focal point? Image distance can become very large, making small input changes important.

Should I mix centimetres and metres? No. Use one unit system throughout the calculation.
