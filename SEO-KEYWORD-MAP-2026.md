# Calcora SEO Keyword Map — 2026-10

## Strategy
- One primary search intent per indexable calculator page.
- Broad terms belong to hubs; specific terms belong to the calculator that actually satisfies them.
- Long-tail and task language are used naturally in headings, explanatory copy, internal links and FAQs.
- Do not create near-duplicate pages just to capture synonyms.
- “Competitor gap” phrases below are opportunity candidates from sampled competitor/category comparisons, not a claim that no competitor anywhere uses the phrase.

## Anti-cannibalization rules
1. “calculator” is not the primary keyword for every page.
2. Homepage owns broad platform discovery.
3. Hubs own category-level discovery.
4. Individual calculators own one calculation/problem.
5. Guides explain formulas, examples, edge cases and use cases; they link to the calculator rather than competing with it.
6. Synonyms are supporting language, not reasons to create duplicate URLs.
7. Country/year terms are used only when the page's calculation genuinely has that geographic or time scope.

## Implementation standard
- Titles and descriptions are written for users first.
- Headings answer the calculation question.
- Formula/method, units, assumptions, worked examples and limitations remain visible.
- Internal links connect parent hub -> calculator -> related calculator -> guide.
- No keyword stuffing, doorway pages, or mass near-duplicate pages.
