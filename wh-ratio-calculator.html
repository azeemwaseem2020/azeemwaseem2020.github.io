Waist-to-height ratio

Waist-to-height ratio (WHtR) is calculated as waist circumference ÷ height, using the same unit for both measurements. Because the units cancel, the result is a dimensionless ratio. It is sometimes used as a simple screening measure related to central adiposity.

Worked example

If waist circumference is 80 cm and height is 170 cm, WHtR = 80 ÷ 170 ≈ 0.471. Measurement technique matters: use the same anatomical location and conditions when tracking changes.

Health context

WHtR is a screening metric, not a diagnosis. It does not directly measure body fat or overall health and should be interpreted with other information. Different guidelines can use different thresholds and populations.

FAQs

Can I use inches? Yes, as long as both measurements use inches. Does it replace BMI? No; it is a different measure. Is one ratio diagnostic? No.

Measurement consistency

Waist-to-height ratio is waist circumference divided by height. Both values must use the same unit. For example, 80 cm waist and 170 cm height gives 0.471. Measure consistently at the chosen anatomical location and avoid comparing values collected using different techniques. WHtR is a screening measure and should not be treated as a diagnosis.
