Square Root Calculator

Calculate the principal square root of a non-negative real number and check the result by squaring it.

What is a square root?

The principal square root of a non-negative number n is the non-negative value whose square equals n. It is written as √n. For example, √25 = 5 because 5² = 25.

Worked examples

Perfect square: √144 = 12 because 12 × 12 = 144.

Non-perfect square: √20 ≈ 4.472136. Squaring that decimal gives a value close to 20, subject to rounding.

How to check a square-root result

Square the displayed answer. If the calculator gives r = √n, then r² should equal n within the limits of decimal rounding. This is a simple way to catch transcription or input mistakes.

Why negative inputs are different

This page calculates real square roots, so a negative input is rejected. In complex-number mathematics, negative numbers can have square roots involving the imaginary unit i; that is a different calculation from the principal real square root provided here.

Common mistakes

  • Do not confuse √n with n ÷ 2.
  • Remember that the principal square root is non-negative.
  • Do not enter a negative value when a real-number square root is required.
  • Keep enough decimal places when a non-perfect square is used in a later calculation.

FAQ

What is the square root of zero?

√0 = 0.

What is the principal square root?

It is the non-negative square root selected by convention for a non-negative real input.

Can this calculator handle negative numbers?

No. It is intentionally limited to real, non-negative inputs.
