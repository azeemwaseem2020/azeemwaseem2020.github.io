PSX Stock Comparison Calculator — Price Return & Dividends

Maintained by Abdul Qadir · Calculation methodology

Compare 2–5 Pakistan Stock Exchange shares over the same period. Enter each stock's start price, end price and cash dividend per share to compare price return and a simplified dividend-inclusive total return.

Data notice: This tool does not fetch live prices or historical PSX data. Use verified prices and the same date range for every stock. Results are arithmetic comparisons, not stock recommendations.

Set the comparison period

Choose a shared date range, then enter prices taken from consistent sources. Use prices adjusted consistently for splits, bonus shares and other corporate actions; otherwise comparisons may be misleading.

Stock inputs

Cash dividends means total cash dividend per share paid during this period. Enter 0 if none. Fees, tax and dividend reinvestment are not included.

How the comparison works

Price return

Price return is calculated as (end price − start price) ÷ start price × 100. It shows only the change in share price.

Simplified total return

This estimate is (end price + entered cash dividends per share − start price) ÷ start price × 100. It assumes the entered dividend belongs to the selected period and does not model reinvestment, withholding tax, fees or corporate-action adjustments.

Worked example

If a share starts at PKR 100, ends at PKR 115 and pays PKR 2 in cash dividends, price return is 15% and simplified total return is 17% before costs and taxes. This example illustrates the formula and is not a claim about any listed company.

How to use the results responsibly

Use the same dates, consistent adjusted prices and dividend information for each company. A return comparison is not a risk-adjusted comparison: it does not measure volatility, drawdown, liquidity, valuation or the chance of future loss.

Frequently asked questions

Does this fetch live PSX prices?

No. Enter verified prices yourself; the tool does not provide a live feed.

Can I compare different date ranges?

For a fair comparison, use one shared start and end date and apply corporate-action adjustments consistently.

Does the total return reinvest dividends?

No. It adds entered cash dividends per share to the end price as a simple estimate; dividend reinvestment is not modelled.

Does the highest return mean the stock is best?

No. Past return alone does not show risk, value, liquidity or future performance.

How to compare PSX shares fairly

A useful comparison starts with a consistent period and consistent inputs. Enter the start and end prices for the same dates for each share, and confirm whether the dates are adjusted for a split, bonus issue, rights issue or other corporate action. If one stock uses a different period or price basis, the percentages can look comparable while answering different questions.

Price return versus dividend-inclusive return

Price return is calculated from the change between the entered start and end prices. A simplified dividend-inclusive result adds the cash dividend per share entered for the period. This is not automatically a fully adjusted total-return series: dividend payment dates, reinvestment timing, taxes, brokerage and corporate actions may not be modeled. Use the same dividend period and clearly stated price basis for every stock.

Interpret the ranking carefully

A higher historical return over the selected dates does not establish that a stock is safer, cheaper or more likely to outperform in future. This comparison does not automatically measure volatility, maximum drawdown, liquidity, valuation, business quality or sector concentration. For risk and holding-level context, review the PSX Portfolio Calculator and Position Size Calculator. For a single completed transaction, use the PSX Profit Calculator.

Data checklist: record each price source and date; use matching date ranges; check corporate actions; state whether dividends are included; and keep transaction costs and taxes separate unless they are explicitly included in your assumptions.
