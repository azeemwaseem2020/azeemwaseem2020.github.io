Weighted Average Calculator

Calculate a weighted average from values and their relative weights. Useful for grades, portfolio allocations, survey data, and other weighted measurements.

Weighted average formula

The weighted mean is Σ(wx) ÷ Σw, where x is each value and w is its weight. Values with larger weights contribute more to the final result.

Worked example

For values 80, 90, 70 with weights 20, 30, 50: (80×20 + 90×30 + 70×50) ÷ (20+30+50) = 77.

How to use the Weighted Average Calculator

  1. Enter values separated by commas.
  2. Enter the corresponding weights in the same order.
  3. Make sure both lists contain the same number of items.
  4. Select Calculate Weighted Average.

How weights work

Weights do not have to add to 100. Only their relative proportions matter as long as the total weight is positive. A zero weight contributes nothing to the result.

Common uses

Weighted averages are used for course grades, investment allocations, performance metrics, price averages, survey summaries, and any situation where observations have unequal importance.

FAQ

Do weights need to total 100? No. Relative weights are sufficient.

Can a weight be zero? Yes, provided the total of all weights is greater than zero.

Can weights be negative? In ordinary weighted-mean applications, weights are normally non-negative; this calculator rejects negative weights.

When to use a weighted average

A weighted average gives different observations different levels of importance. It is appropriate when each value does not contribute equally to the final result.

Worked example

If a score of 80 has weight 60% and a score of 90 has weight 40%, the weighted average is 84. The weights total 100%, which is essential for a standard weighted-average interpretation.

Check the weights

Weights should represent the intended contribution of each value. If they are entered as counts, percentages or proportions, use a consistent basis before calculating.

Weighted-average FAQ

What happens if the weights do not total 100%?

The result may still be mathematically calculable when weights are treated as relative values, but the interpretation should be checked. For percentage weights, normalize or correct them before relying on the result.
