Log Calculator

Calculate logarithms with a selectable base, including natural and common logarithms.

Logarithm formula

logb(x) = ln(x) ÷ ln(b), where x > 0, b > 0 and b ≠ 1.

Worked example

log2(8) = 3 because 2³ = 8. For base 10, log(1000) = 3.

How to use

  1. Enter a positive number.
  2. Enter a valid base greater than zero and not equal to one.
  3. Calculate and check the result.

Domain and common mistakes

For real-valued logarithms, the number must be positive and the base must be positive but not equal to 1. A logarithm answers the question: “To what power must the base be raised to produce this number?” For example, log base 2 of 8 is 3 because 2³ = 8. The logarithm of 1 is 0 for every valid base because any valid base raised to zero equals 1.

Do not confuse the number with the base. The calculator uses the first field as x and the second as b. It uses the change-of-base relationship to compute the result and displays eight decimal places. Very small or very large inputs can be affected by floating-point precision.

Frequently asked questions

What is the difference between log and ln?

“log” often means base 10 in school science, while “ln” means the natural logarithm with base e. Conventions can vary by field, so check which base is intended in the problem.

Can the base be 1?

No. A base of 1 cannot produce different positive values by exponentiation, so the logarithm is undefined for that base.

How can I check a result?

If log base b of x equals y, then b raised to y should equal x, subject to rounding. For example, log base 2 of 8 = 3 because 2³ = 8.
