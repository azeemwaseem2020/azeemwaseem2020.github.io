What is an antilogarithm?

The antilogarithm reverses a logarithm. If log base b of x equals y, then x = bʸ. For common logarithms the base is 10, while natural logarithms use base e.

Worked example

If log₁₀(x) = 3, the antilogarithm is 10³ = 1,000. If ln(x) = 2, then x = e².
